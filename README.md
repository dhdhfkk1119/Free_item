# Free_item
서울 공공데이터 공모전
![display](https://github.com/dhdhfkk1119/Free_item/assets/140272714/9baa6f74-b043-4cdf-bd92-28024aa32725)
개발 프로그램 : vscode
언어 : Python , Flask 
설명 : 서울시 공공데이터에서 사람들에게 무료로 장난감을 대여해주는 지점이 있다 이러한 지점들의 사이트에서 무료로 대여가 가능한 장난감들의 정보를 모아서 사이트에서 보여준다 
크롤링 기술을 이용해서 실시간으로 정보를 가져오고 내용에 변화가 있으면 수정이 된다.
