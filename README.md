## 기술스택

### 개발 프로그램 : vscode

### 언어 : Python , Flask ,html,css

### DB : MYsql , (workbench 8.0) 

### 프로그램 설명 : 서울시 각 지역에서 무료로 장난감을 대여해주는 사이트들의 정보를 한곳에 모아 제공 하여 , 부모들에게 자원을 절약하며 다양한 아이들에게 장난감을 경혐할 수 있는

### 기회를 주는 웹사이트입니다.
### 상품을 클릭시에 상품을 대여할수있는 기존 사이트로 이동합니다.
